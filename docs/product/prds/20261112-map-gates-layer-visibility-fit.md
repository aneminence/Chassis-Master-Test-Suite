## 背景与目标

办公室分析多个路测文件时，3D 地图缺少 2D 的 Gate 编辑入口；全部文件同时叠加难以查看，远隔的轨迹又使全局 Fit 失去意义。用户要求两种地图拥有相同 Gate 操作、文件名前可切换的小眼睛，以及只针对当前选中文件的 Fit。

## 用户故事与方案

- 作为分析人员，我能在 2D/3D 共用的工具条添加、选择、修改宽度、重命名、删除及导入 Gate；3D 点击轨迹放置 Gate，使用与 2D 相同的 Gate 数据。
- 每个离线文件名称前有显示开关；隐藏同步影响曲线、2D/3D 轨迹、比较高亮和地图光标，文件仍保留在列表中，可随时重新显示。
- 显示开关与文件选择独立。选中隐藏文件仍可 Fit 到其位置，Fit 不改变其隐藏状态。全部隐藏时不绘制轨迹或残留标记。
- 两种地图都显示 Fit。Fit 使用选中文件自身有效轨迹范围，远处其他文件和 Gate 不扩大取景范围；没有有效 GPS 时给出提示。
- 显示开关随现有会话记忆恢复，旧会话缺省全部显示。

## 范围边界

不修改原始数据、采样/解析协议、计算输入、导出格式、底图提供方或版本号；不新增原本未实现的 Gate 导出格式。隐藏属于显示操作，计算结果及 Compare 勾选状态保留。

## 技术方案与风险

使用一个共享 Gate 工具条，悬浮在地图内部左上角，Gate 图例位于其下方。3D 使用 WebView2CompositionControl 避免 HWND airspace 遮盖；项目目标 Windows 10.0.17763.0，确保 Windows SDK / WinRT 运行时依赖随程序输出。文件显示状态由会话模型保存；地图始终保留原文件索引，绘制/命中按可见性筛选。3D 场景版本及点击验证保留，Fit 从选中源数据求范围，不从全部可见实体求范围。保持每文件 GPS 毛刺过滤，避免跨文件场地距离过滤误删远处文件。

## 验收标准

- [ ] 2D/3D 显示同一组 Gate 操作，3D 添加与编辑后切回 2D 数据一致。
- [ ] 隐藏一个文件不改变其他文件的颜色、样本索引、选中状态或数据。
- [ ] 全部隐藏、恢复、切文件及 Compare 模式无残留曲线/高亮/车辆点。
- [ ] 两份相距很远的轨迹，分别选中并 Fit，取景只覆盖目标文件；隐藏文件仍可定位但不被自动显示。
- [ ] 会话恢复保留可见性，旧 JSON 兼容。
- [ ] 构建与相关逻辑、渲染、JS 回归通过；实际桌面未测项如实记录。

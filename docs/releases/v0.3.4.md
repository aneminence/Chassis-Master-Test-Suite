# CMTS 0.3.4 Preview

本版本汇总 v0.3.3 之后的全部新增功能和修复：多设备在线采集、离线实时回放、3D 跟随相机与低频轨迹插帧。版本号按用户指定为 0.3.4，继续以预览版发布。

## 多设备在线采集与录制
- 支持 Ctrl 多选连接多台局域网 Android，后连接设备不会替换已连接设备。
- 曲线与 Track Map 按车辆着色，仪表盘汇总多车，状态栏显示连接台数。
- 在线 Files 行切换为 Devices，支持焦点切换、显隐、改色、重命名与单独断开；切换焦点保留其它车历史。
- Remote Rec 对所有已连接设备同时启停录制，并在电脑 Recordings 目录按设备保存独立 VBO，自动处理重名。
- 右侧 Start/Stop 本地录制仍针对当前焦点车；公网和中继不在本版范围内。

## 离线实时回放
- 曲线工具栏下新增播放行，支持播放/暂停、停止、倍速和进度拖动。
- 按样本时间戳和墙钟推进，共享光标同步 Dashboard、地图与曲线。
- 修复进度条点击跳转和时间轴光标对齐；使用主题强调色播放控件。

## 3D Track Map
- 车体改用持久几何，减少实体填充丢失、线框闪烁和反复重建造成的卡顿。
- Follow 开启保留当前距离和构图；左拖平移、滚轮缩放、中键或 Ctrl＋左拖绕车旋转，操作不中断跟随。取消勾选恢复自由视角。
- 新增正后方固定 Chase 相机，与 Follow 互斥；相机和车体同步更新。
- 播放增加时间缓冲，优化光标重复发送、粗采样覆盖和隐藏 2D 刷新。
- 优先读取有效 NCOM INS、已知 VBO IMU/双天线航向；普通 GPS 低于 1 km/h 时保持停车前朝向。真实车身航向与运动方向不同不会被自动校正。
- 在线 DEM 增加超时、一次自动重试及手动重试，失败提示移至角落，移除错误的 ion Token 归因。

## 低频 KML 平滑动画
- 根据当前播放时间，在相邻样本间插值位置和最短航向，避免低频数据逐点跳动；原始记录与分析数据不被改写。
- 暂停保持当前插值位置，拖动立即定位，支持倍速。用户已试用反馈基本正常。
- 超过 10 秒的数据缺口不跨段插值；无时间戳 KML 仍使用合成 1 Hz 时间，无法恢复真实采集速度。

## 安装与验证说明
- 下载 Windows x64 portable ZIP，解压后运行；包内含 .NET 运行时，3D 地图需要 WebView2 Runtime，在线底图和高程需要网络。
- 提供 SHA-256 校验文件。可覆盖前先备份现有程序和用户数据，并关闭运行中的客户端。
- 本地 Release 编译、31 项 JS 地图回归通过；标准 dotnet test 受 testhost 连接超时阻断，未记为通过。
- 隔离浏览器运动测试约 54–60 FPS；不保证所有真实 WPF/文件/网络组合持续达到 30 FPS。

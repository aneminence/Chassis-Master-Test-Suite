# CMTS 0.3.5 Preview

本版本汇总 v0.3.4 之后的功能和修复：加减速切段对齐 VBOX、Test Results 重置与实时追加、成绩两位小数、导入 VBO 时间轴长横线修复，以及 Simulator 直连 DataBus。版本号按用户指定末位加一为 0.3.5，继续以预览版发布。

## 加减速切段对齐 VBOX
- 制动 Speed-to-Speed：起点按配置（如 80 km/h），终点地板 0.8 km/h，距离用速度积分。
- 加速 Speed-to-Speed：起步门槛 0.5 km/h，离开后再掉回 0.5 不重新布防，积分到配置终点。
- 制动 0.8 与加速 0.5 不统一成同一个门槛。

## Test Results 重置、实时追加与两位小数
- 重置会清除成绩表以及曲线/地图上的成绩标注，保留起终点条件；重置后已跑过的成绩不再刷回。
- 线上录制时，每达到一次结束条件自动追加一条成绩（类似 VBOX）；手动 Compute 仍可重算全部数据。
- 成绩数值（Duration / Dist / dV、扇区、Pass、CSV、Dashboard 试验字段）统一显示两位小数；起终点墙钟时间仍为 `HH:mm:ss.fff`。

## 导入 VBO 时间轴长横线修复
- 导入 CMTS/Racelogic VBO 后，孤立的 `000000.000` 或非有限 time 不再把 Time 轴从 0 拉到数万秒、有效数据挤在最右侧。
- 跳过非有限 time 行，丢掉孤立离群时间戳（跨午夜连续段保留）；离线加载时用文件头 `File created on` 把时刻拼成 Unix 毫秒。
- GSpot 经过时间戳不套日期。Time 轴内部仍是 UTC OADate，标签为北京时间。

## Simulator 直连 DataBus
- Simulator 样本经 `SimulatorDataSource` 直接发布到 DataBus，不再经 UDP 推主窗。
- 主程序启动及 Online 不再自动启用 UDP；UDP 手动外部入口仍保留。

## 安装与验证说明
- 下载 Windows x64 portable ZIP，解压后运行；包内含 .NET 运行时，3D 地图需要 WebView2 Runtime，在线底图和高程需要网络。
- 提供 SHA-256 校验文件。可覆盖前先备份现有程序和用户数据，并关闭运行中的客户端。
- 盒内纯逻辑测试 313 项通过。Windows x64 自包含包由 GitHub Actions 构建并上传。

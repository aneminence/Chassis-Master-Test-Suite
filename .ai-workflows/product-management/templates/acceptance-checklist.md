# 验收清单模板 — CMTS

> 每个已批准 PRD 交付前勾选。工程编译/单测仍走 `custom/verification-loop`。

| 字段 | 内容 |
|------|------|
| PRD / 版本意图 | |
| 构建 / 包 | 分支、SHA、或本地包路径（若有） |
| 验收人 | 产品 / 试验 / 用户 |

## A. 工程门禁（质量）

- [ ] `dotnet build` 通过（说明配置）  
- [ ] `dotnet test` 已跑并记录结果（**未跑不得勾**）  
- [ ] 无未批准的范围外改动  
- [ ] 未擅自改 `<Version>` / 打 tag（除非本任务就是发版）  

## B. 产品验收（对照 PRD）

- [ ] 验收标准逐条满足或已书面豁免  
- [ ] 非目标未遭破坏（未偷偷做进范围）  
- [ ] 中英 / 主题（若触及）下关键文案可读  

## C. 试车使用路径（试验）

按实际改：

- [ ] Offline：Load VBO（及如涉及的 KML）→ 看曲线 / 地图 → Compute → 导出  
- [ ] Online：仅当本需求声明覆盖时  
- [ ] 场边约束：网差 / 阳光 / 误触等已按 PRD 检查或注明未测
